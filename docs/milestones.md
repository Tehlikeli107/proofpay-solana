# ProofPay Milestones

## Milestone 1: Product Foundation

Target: Week 1

- Open-source repository and project structure.
- Tested TypeScript payment request core.
- Solana Pay URL generation.
- Static product page for reviewer context.
- Initial documentation.

Evidence:

- Repository link.
- Passing test output.
- Design document.

## Milestone 2: Solana Payment Flow

Target: Week 2

- Wallet connection.
- Payment request creation form.
- Solana Pay QR code and link generation.
- Token selection for SOL and stablecoin payments.

Evidence:

- Deployed app link.
- Demo video of request creation.

## Milestone 3: Verification and Receipts

Target: Week 3

- Solana RPC transaction lookup.
- Verified receipt state.
- Public receipt pages.
- Dashboard for created requests.

Evidence:

- At least 5 verified devnet or mainnet receipts.
- Receipt page links.

## Milestone 4: Launch and Feedback

Target: Week 4

- Public MVP deployment.
- Setup and user documentation.
- Short demo video.
- Feedback from at least 3 Solana or Superteam builders.

Evidence:

- Demo URL.
- GitHub repository.
- Community update post.
